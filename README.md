# ERC Academy Instagram Content System

Canonical source of truth for ERC Academy social content and the **Aprender con ciencia** series.

**For a fresh chat, start with `FRESH_CHAT_WORKFLOW.md`, then follow `START_HERE.md`.**

This repository stores the brand guide, image-generation rules, real visual references, post templates, series history, post log, and Instagram publishing workflow so a new ChatGPT conversation does not require the user to teach the ERC Academy system again.

## Visual reference folders

- `Full Body Shots/` — 25 full-body presenter reference images. Use these to preserve appearance, body proportions, posture, clothing fit, profile angles, walking poses and presentation gestures.
- `Sample ERC_Instagram_Posts/` — 10 ERC Academy Instagram examples. Use these as the primary visual-style references for layout, lighting, typography hierarchy, colors, CTA treatment and overall composition.

The repository is intentionally **public**, and the user has explicitly authorized the included visual references to be stored here.
