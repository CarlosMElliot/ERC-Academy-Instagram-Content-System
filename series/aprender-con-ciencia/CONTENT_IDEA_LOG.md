## How to add a user-supplied source

Add a new row immediately when the user supplies material intended for possible content development.

Example:

| IDEA-0003 | YYYY-MM-DD | INBOX | Short description of what may become the teaching point | Listening | https://example.org/source | — | User supplied this link as a possible basis for a future post. |

Then update the **same entry** as research/production progresses instead of creating disconnected duplicate rows.

## Minimum information to preserve

For every supplied source or serious candidate idea, retain:
- unique idea ID;
- date added;
- current status;
- proposed central teaching point;
- topic family;
- original source/link/identifier;
- associated post number when one exists;
- notes explaining important decisions.
