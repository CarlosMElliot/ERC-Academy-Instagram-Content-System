# ERC Academy Instagram Publishing Workflow

## Target
Instagram account: `@erc.nic`.

## Standard workflow
1. Read the brand files and post log.
2. Generate the ERC Academy artwork in the requested ratio (normally 4:5 for feed posts).
3. Prepare the corresponding Spanish caption.
4. Confirm the post number/status does not create a duplicate.
5. Check ERC Academy Publisher account connection immediately before publishing.
6. Upload/prepare the image through the publisher workflow.
7. Check container/upload state until the publisher reports a completed/ready state.
8. Publish when the current user request authorizes publication.
9. Record the result in `POST_LOG.md`.

## Duplicate protection
If an upload or publish response is ambiguous, do not automatically create or publish a replacement. Check the existing receipt/container/media status first. Historical ERC publishing work has had ambiguous attempts, so duplicate prevention is mandatory.

## Known integration history
The publisher has previously confirmed `@erc.nic` as the connected/matching account. A prior temporary image-transfer problem involved DNS resolution of a workers.dev upload host; that was an infrastructure path problem rather than evidence that the Instagram account itself was disconnected. Re-check current state rather than assuming the historical error persists.
